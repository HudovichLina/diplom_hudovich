# DREAMTASTE

Проект **DREAMTASTE** представляет собой динамический веб-сайт, разработанный на Django, который служит платформой для кондитерской. Основная цель проекта — упростить процесс заказа кондитерских изделий для пользователей, предоставляя удобный интерфейс и функционал.

## Цель проекта

**DREAMTASTE** направлен на решение проблемы, с которой сталкиваются потребители: необходимость искать информацию о кондитерских изделиях в различных источниках и вести переписки с производителями. Мы стремимся создать единое пространство, где пользователи смогут легко находить и заказывать желаемые продукты.

## Стек технологий

- **Язык программирования**: Python
- **Фреймворк**: Django
- **Веб-технологии**: HTML, CSS, JavaScript (+ AJAX)
- **CSS-фреймворк**: Bootstrap
- **База данных**: SQLite

## Функционал проекта

На платформе **DREAMTASTE** пользователи могут:

1. Зарегистрироваться и создать свой профиль, а также при необходимости изменить данные профиля.  
   ![Регистрация](cake_shop/изображения%20для%20редми/регистрация.png)

2. Просмотреть каталог продукции, удобно структурированный по категориям, с возможностью поиска.  
   ![Каталог](cake_shop/изображения%20для%20редми/каталог.png)

3. Узнать информацию о кондитерской и ее контактах.  
   ![Информация](cake_shop/изображения%20для%20редми/информация.png)

4. Создать и отправить форму заказа с необходимой информацией.  
   ![Форма заказа](cake_shop/изображения%20для%20редми/форма%20заказа.png)

5. Внести свои предложения по улучшению продукции через раздел "Пожелания" и проголосовать за идеи других пользователей.  
   ![Пожелания](cake_shop/изображения%20для%20редми/раздел%20пожелания.png)

6. Оставить отзывы на изделия.  
   ![Отзывы](cake_shop/изображения%20для%20редми/отзывы%20в%20каталоге.png)

7. Просмотреть свои отзывы и заказы в профиле, а администратор кондитерской — все заказы клиентов.  
   ![Функционал профиля](cake_shop/изображения%20для%20редми/отзывы%20в%20профиле.png)  
   ![Функционал профиля 2](cake_shop/изображения%20для%20редми/Заказы%20в%20профиле.png)

## Будущие улучшения

Мы планируем активно развивать и улучшать нашу платформу. Вот некоторые из будущих направлений:

- Перевод базы данных на **PostgreSQL** для большей масштабируемости.
- Добавление модуля аналитики с использованием **Pandas** для анализа популярных товаров (для демонстрации работы с модулем добавлен подсчет общего количества реализуемых товаров - отражается на странице .../catalog/categories).
- Расширение функционала для поддержки нескольких кондитеров с возможностью управления их продуктами и отзывами.

Все это только начало! Мы стремимся сделать ваш опыт заказа кондитерских изделий проще и комфортнее.
